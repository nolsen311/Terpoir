Release hashes

The SHA-256 hash of every APK published on GitHub Releases, newest first. Each release's SHA256SUMS is signed with the maintainer's hardware key; this page keeps a copy of both, so you can check a download against two places. How to check the signature and the certificate: Verify your download.

ssh-keygen -Y verify -f allowed_signers -I 64344+nolsen311@users.noreply.github.com -n file -s SHA256SUMS.sig < SHA256SUMS
sha256sum -c SHA256SUMS
